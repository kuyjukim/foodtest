# 냉장고 레시피

집에 있는 재료를 담으면, 지금 만들 수 있는 요리를 찾아주는 웹앱입니다.
레시피 **49개**를 앱 안에 가지고 있어서 인터넷 연결이나 API 키 없이 바로 동작합니다.

## 실행

`index.html` 을 브라우저로 열면 끝입니다. 빌드 과정도, 설치할 패키지도 없습니다.

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 어떻게 찾아주나

레시피마다 재료를 두 가지로 나눠 두었습니다.

- **필수 재료** — 없으면 그 요리라고 부를 수 없는 재료
- **있으면 더 좋은 재료** — 없어도 만들 수 있는 재료

필수 재료가 전부 있으면 **바로 가능**으로, 아니면 **몇 가지 부족**으로 보여주고
부족한 재료 수가 적은 순서로 정렬합니다.

재료 이름은 다음 세 가지 방식으로 느슨하게 맞춰 줍니다.

| 방식 | 뜻 | 예 |
| --- | --- | --- |
| 별칭 | 같은 재료의 다른 이름 | `달걀` → `계란`, `파르메산` → `파마산치즈` |
| 범주 | 구체적인 재료는 큰 범주도 가진 것으로 침 | `삼겹살` → `돼지고기`, `묵은지` → `김치` |
| 대체 | 서로 바꿔 써도 되는 묶음 | `부침가루` ↔ `밀가루`, `국간장` ↔ `간장` |

소금·설탕·간장 같은 **기본 양념 15가지는 집에 있다고 가정**합니다.
없는 양념은 왼쪽 패널에서 체크를 해제하면 그 양념이 필요한 요리가 ‘재료 부족’으로 바뀝니다.

담은 재료와 양념 설정, 화면 테마는 브라우저에 저장되어 다음에 열어도 그대로 남습니다.

## 파일

```
index.html           화면 구조
styles.css           스타일 (밝은/어두운 화면)
app.js               재료 매칭, 자동완성, 필터, 상세 보기
data/recipes.js      레시피 49개
data/ingredients.js  재료 사전 (별칭·범주·대체·기본 양념·빠른 담기 분류)
```

의존성이 없는 순수 HTML·CSS·JavaScript이고, 모듈이나 `fetch` 를 쓰지 않아
`file://` 로 열어도 똑같이 동작합니다.

## 레시피 추가하기

`data/recipes.js` 에 객체 하나를 더하면 됩니다.

```js
{
  id: 'godeungeo-jorim', name: '고등어조림', category: '한식', kind: '국·찌개',
  time: 35, difficulty: '보통', servings: 2, veg: false,
  essential: ['고등어', '무', '고춧가루'],
  optional: ['양파', '대파', '청양고추', '간장', '설탕'],
  steps: ['...', '...', '...'],
  tip: '...'
}
```

새로 쓴 재료 이름은 `data/ingredients.js` 의 `INGREDIENT_CATEGORIES` 에도 넣어 주세요.
빠른 담기 목록에 나오고, 자동완성에도 잡힙니다.
